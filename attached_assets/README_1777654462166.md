# Sales Elevation System

A white-label microapp for technology resellers and VARs — built to help sales teams elevate conversations from transactional vendor interactions to executive-level business strategy discussions.

Built on **React + Vite**. No backend required. Runs entirely in the browser. Checklist state persists via `localStorage`.

---

## What's inside

| Tab | Purpose |
|---|---|
| **Talking Points** | Strategic conversation starters, filterable by practice area |
| **Stakeholder Personas** | Role-by-role profiles: what they care about, opening questions, what to avoid |
| **Discovery Guide** | Step-by-step conversation sequences (opener, elevate, healthcare, cyber) |
| **Objection Handler** | Accordion reframes for the 6 most common objections |
| **Buying Signals** | Tiered signal library with pivot questions for each |
| **Pre-Call Checklist** | 20-item prep tracker across 6 categories, persisted in localStorage |
| **Knowledge Base** | Market intelligence by tech segment, industry, persona, competitive, and signals |

---

## Quickstart

```bash
npm install
npm run dev       # development server
npm run build     # production build
npm run preview   # preview production build
```

Requires **Node.js 18+**.

## Customizing content

All copy lives in two files — no component changes needed to update content.

### `src/data.js`
Core tool content: talking points, personas, discovery sequences, objections, buying signals, and checklist items.

### `src/knowledgeBase.js`
Market intelligence: technology segments, industries, persona enrichment, competitive intel, and market signals.

To add a new talking point:
```js
{
  id: 'tp9', num: 9,
  title: "Your new talking point title",
  body: "The full explanation...",
  tags: ['Tag One', 'Tag Two'],
  tagColors: ['coral', 'teal'],  // coral | teal | amber | purple
  cats: ['all', 'cyber'],        // all | cyber | healthcare | ai | scale
},
```

### Customizing the "Your Firm" tab

The **Knowledge Base → Your Firm** tab is a placeholder — populate it with your firm's specific differentiators, practice areas, internal tools, and GTM priorities. The structure and component are ready; add your content to `src/knowledgeBase.js` following the commented examples in the file.

## Branding

To add your firm name and logo:
1. Update `src/App.jsx` — find the `"Technology Sales"` label and `"Sales Elevation System"` title in the header and replace with your branding.
2. Replace the practice area badge labels in the `PRACTICE_BADGES` array if your focus areas differ.
3. Update `index.html` `<title>` tag.

## Accessibility

- Skip-to-content link
- `role="tablist/tab/tabpanel"` with `aria-selected` / `aria-controls`
- `aria-pressed` on toggle buttons and filter buttons
- `role="progressbar"` with `aria-valuenow/min/max`
- `:focus-visible` outlines throughout
- Dark mode via `prefers-color-scheme`

## Deployment

```bash
npm run build   # outputs to dist/
```

**Vercel:** `npm i -g vercel && vercel`

**Netlify:** Drag `dist/` to [app.netlify.com/drop](https://app.netlify.com/drop)

**GitHub Pages:** Set `base: '/your-repo-name/'` in `vite.config.js`, push `dist/` to `gh-pages` branch.
